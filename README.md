# QotD

macOS Desktop Widget + companion app for personal quotes that rotate on a schedule.

## Requirements

- macOS 15 Sequoia or later

## Install

1. Download the latest zip from [Releases](https://github.com/Dvir75/QotD/releases).
2. Unzip and open **QotD**.
3. If macOS blocks it: right-click the app → **Open** → **Open**.
4. Add the widget: right-click the Desktop → **Edit Widgets** → find **QotD**.

## Updates

In the app, open **Settings** (or the menu-bar icon) and choose **Check for Updates…**.
